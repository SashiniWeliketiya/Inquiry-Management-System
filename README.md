# Inquiry Management System

A full-stack Inquiry Management System built for efficient handling of customer inquiries, status tracking (New, In Progress, Resolved), and staff user management.

---

### 1. Prerequisites
- Node.js (v18 or higher)
- PostgreSQL
- Git
